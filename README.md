## هيكل المشروع
- `docs/` — الواجهة (تُنشر على GitHub Pages)
- `app.py`, `database.py` — الخادم وقاعدة البيانات (SQLite)
- `docs/config.js` — عنوان الخادم

## إعدادات الخادم (متغيرات البيئة)
| المتغير | الوظيفة |
|---|---|
| `LAMH_ADMIN_PASSWORD` | كلمة سر المسؤول الأولى |
| `LAMH_CORS_ORIGIN` | نطاق الموقع المسموح له (مثل `https://USER.github.io`) |
| `LAMH_DB` | مسار ملف القاعدة |
| `LAMH_BEHIND_PROXY` | `1` عند الاستضافة خلف وسيط |

> التفاصيل الكاملة في التقرير والعرض التقديمي.
